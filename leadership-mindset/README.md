# leadership-mindset

Run yourself and the company. The skills that turn real decisions into values, cut complexity every quarter, keep growth inside guardrails, apply the right decision frame, protect the founder's focus and energy, and build a healthy team. Three of these run at every stage.

## What it does

Handles the founder's own operating system and the company's. Values come from costly decisions (not posters), growth stays profitable and sustainable, and the always-on skills — decisions, productivity, team-building — fire whenever a hard choice, a slump, or a people issue comes up.

## Installation

```
/plugin marketplace add codezard/founder-os-marketplace
/plugin install founder-core@founder-os-marketplace
/plugin install leadership-mindset@founder-os-marketplace
```

Install `founder-core` first.

## Skills

| Skill | Stage | Reads → Writes |
|---|---|---|
| `company-values` | 5 / first hire | `decision-log.md` → `23-values.md` |
| `minimalist-review` | 4+ (quarterly) | feature/tool/channel/meeting lists → `24-minimalist-review-<quarter>.md` |
| `sustainable-growth` | 5 | `20-financial-model.xlsx`, `06-pmf-report.md` → `25-growth-plan.md` |
| `decision-frameworks` | any | the decision → `decision-log.md` |
| `founder-productivity` | any | current stage, hours, energy → `week-template.md`, `weekly-reviews.md` |
| `team-building` | any | team, values → `26-team-operating-system.md` |

`decision-frameworks`, `founder-productivity`, and `team-building` are stage-independent (always on). Check gates with `/founder-os:status`.
