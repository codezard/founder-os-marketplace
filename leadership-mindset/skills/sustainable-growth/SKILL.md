# Sustainable Growth

Grows within explicit guardrails and exhausts one lever before adding the next. Inherits `founder-core/references/principles.md` (A6) and the glossary (NRR, Rule of 40).

**Owner role:** Founder-CEO
**Stage:** 5 — Grow Sustainably

## Step 0 — Constraints & upstream
- Read `founder/constraints.md` (founder hours and energy are guardrails, not afterthoughts).
- Upstream: `founder/20-financial-model.xlsx`, `founder/19-unit-economics.md`, `founder/06-pmf-report.md`, team capacity. Run those first if missing.

## Inputs
Financial model, unit economics, PMF report, team capacity, founder hours and energy.

## Process
1. **Set the Growth Guardrails:** a growth-rate target that keeps profitability ≥ 10% (or a chosen burn), a gross-margin floor, a founder-hours cap, and a support response-time floor.
2. **Sequence expansion levers by risk:** raise prices → reduce churn → expand existing accounts → add an adjacent segment → add a second channel → add a second product. Only move to the next when the current is exhausted or below threshold.
3. **Capacity plan:** at what MRR does each next hire become required? Pre-decide, don't react.
4. **Define the Quality Signals that pause growth:** churn up 2 months, NPS down, support backlog, founder < 6 hours sleep.
5. **Quarterly:** run `minimalist-review`, then this skill, then update the financial model.

## Outputs
`founder/25-growth-plan.md`.

## Utils
**Guardrail template.** **Expansion-lever sequence.** **Capacity trigger table.** **Quality-signal dashboard spec.**

## Gate
`Growth ≥ 5% MoM with guardrails intact for 3 consecutive months.` End with `Gate: PASS/OPEN — because …`.

## Anti-patterns
Growth at any margin. Second product before the first is on autopilot. Hiring ahead of revenue without a plan.

## Evals
- **Should fire:** "How fast should we grow without burning out?" / "When do I add a second product?" / "What's a healthy growth rate for us?"
- **Should NOT fire:** "What should we cut?" (→ minimalist-review) / "Build the model." (→ financial-model)
- **Golden run checklist:** upstream read; guardrails set (profit, margin, founder hours, support); levers sequenced by risk; capacity triggers pre-decided; quality-signal pause list; quarterly ritual; `25-growth-plan.md` created; gate line emitted.
